# ADR: имя NaBTools

Статус: принято владельцем 23.10.2026.

Этот документ закрепляет имя проекта при выделении из исходной библиотеки.
Архитектура движка и модулей из [исходного ADR](ADR_20261023_bt-engine-modules.md)
сохраняется.

Проект и каталог называются NaBTools. Современный C++ API использует заголовки
`<NaBTools/...>` и namespace `NaBTools::runtime`. Историческая legacy-библиотека
на дату этого решения оставалась совместимой. Это исключение отменено
[решением от 29.10.2026](ADR_20261029_complete_naming.md).
Создаётся отдельный приватный репозиторий NaBTools.

Переход потребителей описан в [инструкции миграции](../readme_nabtools_migration_ru.md).
