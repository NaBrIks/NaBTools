# ADR: единые имена во всём проекте

Статус: принято владельцем 29.10.2026.

Решение охватывает весь репозиторий: исходную библиотеку, современный runtime,
заголовки, namespaces, генераторы, build targets, настройки, CBOR IDs,
хранилище браузера, инструменты и документацию. Используются `NaBTools`,
`nabtools` и `NABTOOLS` согласно назначению и регистру соответствующего API.

Это решение заменяет исключения совместимости из ADR от 23.10.2026.
Старые имена не сохраняются ни как aliases, ни как запасные пути чтения.
Потребители обновляются вместе с библиотекой; сохранённые настройки переносятся
на текущие имена. Исходный секрет при смене метки формата не преобразуется.

История Git, архивные дампы и локальные журналы проверок не переписываются.
Архитектура BtEngine, модулей, Actions и границы приложения сохраняется.
