# Единые имена NaBTools

По решению владельца от 29.10.2026 переименование распространяется на весь
проект, включая исходную библиотеку, конфигурацию и прикладной обмен.
Прежние исключения ради совместимости отменены. См. [ADR](adr/ADR_20261029_complete_naming.md).

| Область | Текущее имя |
|---|---|
| Проект, компонент и PlatformIO library | `NaBTools` |
| Современные заголовки и namespace | `<NaBTools/...>`, `NaBTools::runtime` |
| Модули устройств | `<NaBTools/devices/...>`, namespace `NaBTools::runtime` |
| Флаги C++ и Kconfig | `NABTOOLS_*`, `CONFIG_NABTOOLS_*` |
| CBOR schema и handler IDs | `nabtools.*` |
| Ключи браузерного хранилища | `nabtools.*` |
| Исследовательская прошивка | `nabtools_research` |
| Wi-Fi макросы приватного заголовка | `NABTOOLS_WIFI_SSID`, `NABTOOLS_WIFI_PASSWORD` |
| Формат сохранённого ключа SmartTag | `nabtools.samsung.smarttag.owner.v1` |

Обновите include, namespace, флаги и потребителей CBOR одновременно с прошивкой
и вебкой. Прежние заголовки, schema IDs и флаги не поддерживаются как aliases.
Предпочтения интерфейса в новом префиксе устанавливаются заново; старые ключи
не читаются и не влияют на интерфейс. Настройки SDK из прежнего окружения
нужно перенести на текущие имена либо создать заново по defaults.

Локальный файл ключа SmartTag можно переоформить текущим инструментом;
значение секрета при этом не меняется и не включается в публичные материалы.
Включаемый приватный Wi-Fi заголовок должен содержать новые макросы.

В версии 0.3.0 плоская исходная реализация удалена после переноса полезных
возможностей. Одного изменения namespace для старого потребителя недостаточно:
нужны модульные include, явная композиция BtEngine и Actions.
См. [соответствия и удалённые части](readme_retired_code_ru.md).

Манифест выделения сохраняет хеши исходного снимка. В нём есть исторические пути
уже удалённых файлов; это не перечень текущего дерева и не текущая checksum-проверка.
Происхождение снимка доступно в истории Git.
Лицензии и notices сохранены.
