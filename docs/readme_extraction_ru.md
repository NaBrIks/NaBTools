# Выделение проекта 2026-10-23

Исторический отчёт. После выделения появился модульный runtime; 29.10.2026
полезные оставшиеся возможности перенесены, а прежняя реализация удалена.
См. [аудит и текущие ограничения](readme_retired_code_ru.md).

Источник: исходная Bluetooth-библиотека проекта `ESP32-BLETPMS-and-more`.
Целевой проект: `NaBTools`.
HEAD исходного репозитория при переносе:
`758f784126adf48b8d486945449104f372b2069a`.

Перемещены `src`, `Python`, `Doc`, `library.json`. Для каждого из 617 исходных
файлов (2 490 636 байт, включая SIG-данные, исключая служебный `.git`) при переносе
проверен SHA256. [Манифест](extraction-source-manifest.json) фиксирует исходное
состояние до поправок упаковки; это не обещание неизменности будущих версий.

SIG submodule исходного проекта оставлен зарегистрированным на старом месте,
на commit `4f955efbe9144b01c02e2ee2044f43d510cc8da0`. В новый проект скопированы
его данные и notices без `.git`, указывающего внутрь чужого репозитория.
Новый проект не зависит от доступности старого submodule при сборке/генерации.
Это snapshot, а не автоматически обновляющийся submodule.

При первом выделении реализация и исследовательские принты были сохранены.
Упаковка тогда объявляла
зависимость `johboh/nlohmann-json ^3.12.0`, C++23 и отсутствие архивной линковки,
необходимое существующей статической авторегистрации распознавателей.
Добавлен минимальный пример сборки всего legacy-кода без LVGL/веба.

Сейчас поддерживается только модульный runtime. Названия
заголовков и API описаны в [миграции](readme_nabtools_migration_ru.md).
Подробности размещения — [структура файлов](readme_layout_ru.md).

## Происхождение и лицензии

`library.json` исходника называл автора KOE и версию 0.1.0, но не задавал лицензию.
В исходном репозитории лежит GPL v3 LICENSE; его точная копия сохранена здесь.
Это фиксация происхождения, не выбор новой лицензии и не автоматическое
распространение GPL на материалы SIG. Исходные notices SIG остаются в YAML.
Перед публичным выпуском условия собственного кода и сторонних таблиц следует
оформить отдельно. При первом выделении новый номер версии не задавался.

Исторические Doc/ и ранние Python-скрипты удалены вместе с прежней реализацией;
они доступны в истории Git. Для новой работы точкой входа служат корневой README
и текущие docs. Ни обновление upstream, ни регенерация справочников при первом
выделении не выполнялись. Позднее SIG обновлён отдельным изменением.
