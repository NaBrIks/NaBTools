# Проверка исследовательского примера на ESP32-C6

На ESP32-C6 проверены приём BLE рекламы, распознавание поддерживаемых устройств,
создание/удаление экземпляров и общий просмотр CBOR в браузере. Название компании
взято из выбранного SIG-профиля, а распознавание протокола требует его признаков.
Одного manufacturer ID для этого недостаточно.

Успешная сборка отдельно не доказывает приём радио, свежесть данных или работу
прикладного драйвера. Для повторной проверки следует сопоставить поток сообщений,
время, поколения экземпляров и фактические результаты команд.

Актуальные интерфейсы: [GATT](readme_gatt_ru.md), [WS/CBOR](readme_websocket_ru.md).
Сетевые адреса, USB-порты, идентификаторы приборов и локальные журналы не входят
в публичную документацию.
