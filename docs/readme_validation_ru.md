## Самостоятельная сборка

Минимальный пример `examples/espidf_smoke` компилирует все исходники legacy
библиотеки и линкует прошивку без LVGL, yaidfws и исходного TPMS-приложения.
PlatformIO linked dependency разрешается непосредственно в новый проект.

Инструменты проверки: PlatformIO, espressif32 6.10.0, ESP-IDF 5.4.0,
Xtensa GCC 14.2.0, nlohmann-json 3.12.0, target ESP32-S3.

Команда: `./tools/build_smoke.ps1` (необязательный `-CoreDir <tool-cache>`).
Результат: **SUCCESS**, компиляция и линковка завершены. В map присутствуют
статические экземпляры всех трёх прежних распознавателей (TPMS, SmartTag, Test).
После согласования flash-конфигурации примера с платой 8 MiB финальный build log
не содержит compiler warnings/errors или предупреждения о размере flash.

## Повторяемая проверка

```powershell
cmake -S . -B local/native-build
cmake --build local/native-build --config Debug
ctest --test-dir local/native-build -C Debug --output-on-failure
npm ci
npm test
pio run -d examples/research -e c6
```

Native inputs синтетические; реальную работу следует проверять отдельно на
совместимом BLE контроллере и приборе. Локальные журналы сборки/прошивки,
захваты и фотографии оборудования не являются частью публичного репозитория.
